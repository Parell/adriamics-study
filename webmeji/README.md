# Webmeji companion

This directory vendors the default Webmeji sprite set and runtime for the
notes site. The runtime and configuration are adapted from
[lars-rooij/webmeji](https://github.com/lars-rooij/webmeji), by Lars de Rooij,
and are distributed here with the upstream project’s attribution.

The site uses one default `SHIMEJI_CONFIG` companion. Sprite URLs are absolute
(`/study/webmeji/shimeji/...`) so the same bundle works on landing, study,
and practice pages. The Notes UI provides a persistent toggle for hiding or
showing the companion.
